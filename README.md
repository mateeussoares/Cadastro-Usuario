# Cadastro de Usuários

Uma aplicação backend em **Java com Spring Boot** que implementa um **CRUD básico de usuários**, desenvolvida com foco em aprendizado prático de APIs REST, organização em camadas e persistência de dados.

---

## 🧠 Sobre o Projeto

Este projeto consiste em um sistema simples de **Cadastro de Usuários**, permitindo realizar operações básicas de um CRUD:

- Criar usuários
- Listar usuários
- Buscar usuário por ID
- Atualizar informações
- Remover usuários

O objetivo principal é **consolidar fundamentos de desenvolvimento backend** utilizando o ecossistema Spring, boas práticas de estruturação e separação de responsabilidades.

---

## 🚀 Tecnologias Utilizadas

- ☕ **Java 17+**
- 🌱 **Spring Boot**
- 📦 **Maven**
- 🗄️ **Spring Data JPA**
- 💾 **Banco de dados H2**
- 🔗 **API REST**
